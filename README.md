## About

BSIT graduate from Southway College of Technology and Flutter developer,
now applying that development background to cybersecurity — building
hands-on security skills through picoCTF exercises and documenting the
process publicly rather than waiting to feel "ready."

## Sections

- **Hero** — terminal-style intro
- **About** — background and current focus
- **Skills** — development, security foundations, tools, in-progress areas
- **Credentials** — education and certifications (earned + planned)
- **Log** — Flutter projects and CTF write-ups, framed as dated log entries
- **Contact** — email, GitHub, LinkedIn, TryHackMe

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- Deployed on [Vercel](https://vercel.com)

## Running locally

\`\`\`bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
npm install
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000).

## Deploying

Push this repo to GitHub, then import it at [vercel.com/new](https://vercel.com/new).
Vercel auto-detects Next.js — no config needed. Every push to `main` redeploys automatically.
